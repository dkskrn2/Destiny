# 콘텐츠, VOD, 커뮤니티 인용 플로우 설계

## 목표

명리결 사이트에 읽기 콘텐츠, VOD 시청, 커뮤니티 토론을 연결하는 서비스 흐름을 추가한다. 사용자는 블로그성 콘텐츠를 읽고 커뮤니티에 인용 글을 작성할 수 있으며, 강의 상세에서 VOD 시청 페이지로 이동해 학습을 이어가고 커뮤니티 질문이나 상담 예약으로 전환할 수 있다.

## 추가 페이지

### 콘텐츠 목록: `pages/content.html`

- 블로그/콘텐츠 게시물 목록을 제공한다.
- 카테고리는 `입문`, `학습법`, `상담 준비`, `사례 읽기`를 기본으로 둔다.
- 추천 콘텐츠 카드, 일반 목록, 사이드바 인기 태그/추천 강의/상담 CTA를 포함한다.
- 헤더와 메인 화면에서 접근 가능한 운영 페이지로 취급한다.

### 콘텐츠 상세: `pages/content-detail.html`

- 콘텐츠 본문, 작성자/발행일/읽는 시간, 목차, 핵심 요약, 관련 콘텐츠를 제공한다.
- 로그인한 유저가 사용할 수 있는 서비스 상태를 표현하기 위해 `커뮤니티에 인용하기` CTA를 둔다.
- CTA는 `pages/community-write-quote.html`로 이동한다.
- 비로그인 상태는 이번 정적 구현 범위에서는 별도 페이지로 만들지 않고 안내 문구로만 표현한다.

### 인용 작성: `pages/community-write-quote.html`

- 콘텐츠 원문 카드, 인용 문장, 작성자 의견 입력 영역을 제공한다.
- 사용자가 “원문을 바탕으로 내 질문/의견을 커뮤니티에 작성한다”는 흐름을 명확히 보여준다.
- 등록 버튼은 정적 CTA로 처리하고, 실제 저장/검증 로직은 후속 백엔드 범위로 남긴다.

### VOD 시청: `pages/vod-watch.html`

- 강의 영상 플레이어 mock, 강의 목차, 현재 차시 정보, 학습 메모, 다음 행동 CTA를 제공한다.
- 실제 영상 재생 기능은 구현하지 않고, 정적 플레이어 UI와 진도/목차 상태를 만든다.
- CTA는 커뮤니티 질문 작성, 다음 강의, 상담 예약으로 이어진다.

## 기존 페이지 변경

- `index.html`: 주요 내비게이션과 섹션에 `콘텐츠` 진입점을 추가한다.
- `pages/course-basic.html`, `pages/course-ten.html`, `pages/course-flow.html`, `pages/course-sinsal.html`: 주요 CTA에 `VOD 시청하기` 경로를 추가한다.
- `pages/community.html`: 일반 글 외에 `콘텐츠 인용 글`, `강의 질문 글` 케이스를 피드에 추가한다.
- 공통 푸터에는 콘텐츠 링크를 추가하지 않는다. 푸터는 회사/정책/고객지원 중심으로 유지한다.

## UX 원칙

- 콘텐츠는 “운세 결과”가 아니라 학습 자료로 보이게 만든다.
- 커뮤니티 인용 글은 원문 출처와 사용자의 의견이 구분되어야 한다.
- VOD 시청 페이지는 실제 강의 서비스처럼 보여야 하며, 단순 상세 페이지 복제가 아니어야 한다.
- 모든 신규 페이지는 기존 `site-header`, `site-footer`, `theme-*`, `app-pages.css` 패턴을 사용한다.

## 구현 범위

- 정적 HTML/CSS만 수정한다.
- JavaScript 저장, 로그인 판별, 실제 동영상 재생, 결제/수강 권한 검증은 포함하지 않는다.
- 모든 신규 링크는 로컬 정적 서버에서 `200`으로 확인한다.

## 검증

- `git diff --check`
- 신규 페이지 4개와 주요 연결 페이지 `200` 응답 확인
- 삭제된 운세 페이지 링크가 재도입되지 않았는지 검색
