추천: 정적 HTML로 화면 흐름 완성

현재 사이트 구조에 맞춰 `content.html`, `content-detail.html`, `community-write-quote.html`을 만들고 커뮤니티 목록에 인용 글 케이스를 추가합니다. 지금 단계에 가장 빠르고 명확합니다.

B

데이터 모델까지 염두에 둔 정적 화면

화면은 정적이지만 글 ID, 작성자, 인용 원문, 로그인 상태 같은 데이터 필드를 UI에 명확히 드러냅니다. 추후 백엔드 연결을 더 쉽게 만듭니다.

C

최소 구현

목록과 상세만 추가하고 인용 작성 페이지는 버튼/상태 정도로 단순 처리합니다. 빠르지만 서비스 플로우 검증에는 약합니다.
